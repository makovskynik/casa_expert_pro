# Список фотографий для сайта Casa Expert

## Обязательный минимум перед запуском

1. Один сильный горизонтальный hero-кадр 3:2 или 4:3.
2. По одному кадру для Renovation, Solar, Bathrooms/Kitchens и Building Services.
3. Один подтверждённый кейс: 6–10 фотографий, включая общий план и детали.
4. Команда или ответственный специалист на объекте.
5. Один процессный кадр: замеры, проверка или handover.

## Для каждого проекта

- общий вид до работ;
- проблемная зона крупно;
- 2–4 фотографии процесса;
- общий вид после работ с того же ракурса;
- 2–4 качественные детали;
- вертикальный кадр для stories;
- горизонтальный кадр для сайта/OG;
- письменное разрешение владельца на публикацию.

## Технические требования

- исходник не меньше 2400 px по длинной стороне;
- без WhatsApp-компрессии;
- убрать лица, номера домов и регистрационные номера без согласия;
- хранить оригинал отдельно от web-версии;
- WebP/AVIF генерировать из оригинала, а не наоборот.
